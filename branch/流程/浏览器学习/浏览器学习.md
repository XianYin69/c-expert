# 浏览器学习
横切节点：遇不明白强制联网取证后再作答。
## 动作
1. 触发即执行：`python -B scripts/browser_learn.py --query "<问题>" --out tmp/learn`
   （内部派 file_ops 的 ff_lite.py search/fetch）。
2. 网络动作须 `:grant network`；未授权先申请，不得绕过。
3. 蒸馏入库：结论写 knowledge 链 + `references/<领域>/<主题>.md`，附 URL 与抓取时间。
4. 回原节点记逻辑链：`--from 不明点 --to 采用方案 --why 出处`。
5. 复用既有取证，同一问题不重复抓取。
## 产出
- `tmp/learn/*.md` 取证件 + 链上一条经验。
## 兜底
- 不可达：记 `process_chain.py interrupt`，降级本地 references/ 并明示「未联网确证」。
