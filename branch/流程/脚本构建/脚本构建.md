# 脚本构建
编写探针与机制脚本（经 code-guidelines / pavedpath-code）。
## 动作
1. 一脚本一职责：文本探针只做静态启发式，编译类只调编译器，不混写。
2. 红线：单文件 ≤50 行、英文文件名、UTF-8、`--dry-run` 默认（写盘类）、无裸 except。
3. 输出分级：blocking / major / minor / info + 出处锚点（[iso] [cref] [google] [book] [man]）。
4. 探针必须自带「无编译器降级」路径，禁止把未运行写成已验证。
5. 复用机制脚本：check_links / browser_learn / knowledge_fetch / logic_chain / process_chain 等。
## 产出
- `scripts/*.py` + `scripts/scripts.md` 索引。
## 兜底
- 脚本坏味道：数据外移 `asset/`，脚本只留逻辑（脚本不限行数，50 行红线仅限 markdown）。
- 规则误报高：降 severity 并在 docstring 声明「启发式，须实测确证」。
