# 构建测试
实跑验证：编译、探针自测、回归。
## 动作
1. 语法检查：`python -B scripts/gcc_check.py <src> --std c11`（无编译器 → 记 SKIP，不得称通过）。
2. 探针自测：对 `tmp/fx/` 夹具逐支实跑，断言 rc=0 且命中数 ≥1（缺陷须被检出）。
3. 编译自检：`python -B -m py_compile scripts/*.py` 全绿。
4. 体量自检：`python -B scripts/lint_check.py --path .` 问题数 = 0。
5. 失败即回脚本构建修复，并记 `process_chain.py interrupt`。
## 产出
- `tmp/build_report.md`：逐支 rc / 命中数 / 降级说明。
## 兜底
- 无编译器：以文本探针 + sanitizer_cmd 生成命令交用户实测，明示未验证。
