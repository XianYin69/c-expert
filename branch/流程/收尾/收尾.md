# 收尾
交付、提示词、垃圾回收与 git 收口。
## 动作
1. 提示词四格式：`agent/agent_prompt.md`、`agent/CLAUDE.md`、`agent/instructions.md`、
   `agent/.cursorrules`，各一句话「使用 `c-expert` skill 来完成用户请求。」。
2. 自更新比对：`python -B scripts/self_update.py report`（接口见 update/update.md）。
3. 垃圾回收：`python -B scripts/garbage_collect.py --path tmp --age 0 --yes`，tmp 残留删除。
4. git：每步功能分支提交 → 审核通过合 `dev` → 整体审查通过 `dev` 合 `main`；
   推送前须用户确认（本次由调度方统一推送，本技能不 push、不建远端）。
5. CHANGELOG 记 0.1.0。
## 产出
- 交付清单（绝对路径）+ 核验数据（行数/文件数/悬空链接/脚本 rc/书目确证计数）。
## 兜底
- git 写操作被门禁拒：报告缺 `:grant danger`，保留工作树，禁止伪造历史。
