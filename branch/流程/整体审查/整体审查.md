# 整体审查
九项标准整体审查（双链辩论 + 悬空链接归零）。
## 动作
1. 九项：①目录齐备 ②SKILL.md ≤50 行且含 frontmatter ③流程节点闭合 ④脚本实跑通过
   ⑤悬空链接 = 0 ⑥约束齐备 ⑦依赖只引用不内嵌 ⑧书目来源标注诚实 ⑨tmp 无残留入库。
2. 链接：`python -B scripts/check_links.py --root .` 必须输出「悬空链接数 = 0」。
3. 体量：`python -B scripts/lint_check.py --path .` 必须「问题数 = 0」。
4. 双链辩论：`python -B scripts/logic_chain.py debate --pro <论据> --con <论据>` 记 pro/con 与 verdict。
5. 失败：记 `process_chain.py interrupt`，修复后 resume；重试达 10 次触发 penalty 熔断。
## 产出
- `tmp/review.md` 九项结论 + 逻辑链 debate 记录。
## 兜底
- 不可修复项：降级为已知限制写入 CHANGELOG，并向用户明示。
