# 分支分析
分析分支与取舍，标注转派边界。
## 动作
1. 方言分支：C89/C99/C11/C17/C23 特性差异 → 由 portability_scan 取证，禁凭记忆。
2. 平台分支：POSIX / Windows / 嵌入式 freestanding；头文件与 API 可用性分别标注。
3. 判据分支：UB（blocking）/ 可移植（major）/ 风格（advisory）三档，各档引用不同出处。
4. 转派分支：并发架构 → concurrency-design；编码规范 → code-guidelines；
   已验证范式 → pavedpath-code；UI → ui-design；存储 → database-management。
## 产出
- `tmp/分支表.md`：分支 × 判据 × 出处 × 转派目标。
## 兜底
- 分支不可判定：记中断并向用户取一要素（编译器版本或目标平台）。
