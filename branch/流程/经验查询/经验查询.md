# 经验查询
复用既往取证，避免重复劳动。
## 动作
1. 链检索：`chain recall` 查 memory/knowledge/logic 链既往 C 结论。
2. 叶定位：`python -B scripts/classify_topic.py --text "<问题>"` 映射知识叶。
3. 叶要点：`python -B scripts/knowledge_index.py --leaf <id>` 取要点与出处锚点。
4. 既往交付：查 `references/` 与 `asset/knowledge/`，命中即引用，不重复抓取。
## 产出
- 经验清单：可复用结论 + 需新取证的缺口。
## 兜底
- 无既往经验：记缺口，转知识库构建/浏览器学习取证。
