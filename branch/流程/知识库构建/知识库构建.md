# 知识库构建
检索并确证权威文献，落 references/（穷尽至不可再拓扑）。
## 动作
1. 派 file_ops 取证：`ff_lite.py search` / `fetch`，优先中国大陆可达源（book.douban.com 及其
   `j/subject_suggest` 接口、知乎、github.io 镜像）；境外源 WinError 10060 即记不可达。
2. 检索规避：≥4 词英文书名会被切成词典页 → 改用中文书名或「单词+出版社」。
3. 每条目落 `references/<领域>/<条目>.md`：书目事实（作者/译者/出版社/出版年/ISBN/页数）+ 摘要 + 映射叶。
4. 来源标注：`[联网]`（附 URL 与取证日期）/ `[本地]`（未确证，禁附 URL）。
5. 拓扑检查：知识叶不可再分即止；新增叶须同步 asset/knowledge 与 asset/checklists。
## 产出
- `references/references.md` 索引 + 各条目 md + `asset/knowledge_tree.json`。
## 兜底
- 检索全不可达：整条标 `[本地]` 并在交付中声明未联网确证。
