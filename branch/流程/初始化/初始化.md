# 初始化
两条路径的共同前置：建立工作空间与许可基线。
## 动作
1. 确认目标目录；未指定时固定路径沙盒作业：`python -B scripts/sandbox.py create --name c-expert`。
2. 建 tmp 工作镜像：生成文件一律入 tmp，禁止直写 skill 目录。
3. 写 MIT `LICENSE`（工作区根与 tmp 各一份，已有不覆盖）。
4. 无 `.git/` 即 `git init`（不得跳过）；核对 `.gitignore` 含 `tmp/` 与 IDE 目录。
5. 挂载五大机制：逻辑链、过程链、上下文压缩、垃圾回收、惩罚。
6. 依赖自检：`python -B scripts/deps_check.py`（file_ops / code-guidelines / pavedpath-code / python / git）。
7. 编译器探测：`python -B scripts/gcc_check.py --probe`（无编译器即记为取证缺口）。
## 产出
- `LICENSE`、`.gitignore`、功能分支 `feature/init`、逻辑链首条。
## 兜底
- 依赖缺失：记 `process_chain.py interrupt` 并报告缺项，禁止伪造能力继续。
- 无 C 编译器：降级为文本探针取证，收尾时明示「未编译验证」。
