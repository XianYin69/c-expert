# 大纲构建
构建并审阅初步结构大纲（技能本体 + 交付骨架）。
## 动作
1. 列目录骨架：SKILL.md / agent/ / asset/ / branch/流程/ / dependence/ / references/ / resistance/ / scripts/ / update/。
2. 定知识叶：十二叶（见 references/知识树/知识树.md），每叶 → asset/knowledge + asset/checklists 一对一。
3. 定探针集：gcc_check · memory_audit · ub_scan · header_deps · makefile_probe · cmake_probe ·
   portability_scan · concurrency_probe · const_audit · perf_advice · sanitizer_cmd · lint_config_gen。
4. 大纲自审：单文件 ≤50 行可行性、链接闭合性、无内嵌他技能正文。
## 产出
- `tmp/大纲.md`：目录树 + 叶清单 + 脚本清单 + 依赖清单。
## 兜底
- 大纲超红线：拆文件（细则外移 asset/），不得放宽 ≤50 行。
