# resistance（约束库 / 兜底库）

本目录存放本 Skill 不可逾越的规则、红线与异常降级策略。

## 应存什么

- 「必须 / 禁止」类约束（自然语言、每条 ≤ 50 行）。
- 执行期触发兜底（fallback）的条件与降级动作。
- 与外部系统（网络、git、依赖技能）的交互边界。

- [`审查约束/`](审查约束/审查约束.md)：整体审查得出的项目级约束。

## 遵守原则

1. 修改本目录内容前须经 [update 审批流](../update/update.md)。
2. 违反本目录的操作不得执行，除非有显式兜底方案覆盖。
3. 本目录变更须记 [`CHANGELOG.md`](../CHANGELOG.md) 并注明违规后果。
4. 约束之间冲突时交 constraint_arbiter 仲裁，不得私自取其一。
